# 사용 흐름·디자인

## 핵심 시나리오

### S1. 오후 회의실 예약 (메인 플로우)
1. 직원이 "오늘 오후 3시에 팀 회의를 잡아야 해" 생각하고 앱 열기
2. 회의실 목록 보기 (현재 시간대 기준 색상 표시)
3. 5인 이상 수용 회의실 클릭
4. 시간대 보기 (14:00~18:00 슬롯 표시, 예약 불가 시간 회색 처리)
5. "15:00~15:30" 클릭 → "예약하시겠어요?" → 예약 완료
6. 확인 메시지 + 예약 상세 보기

### S2. 예약 취소 (다른 상황)
1. 직원이 자신의 예약 목록 열기
2. "오후 3시 회의실A" 예약 선택
3. "취소" 클릭 → 확인 → 완료

---

## 화면 구조

```
├─ 메인 화면 (회의실 카드 그리드)
│  └─ 회의실별 가용 슬롯 표시
├─ 대시보드 (시간별 전체 현황)
│  └─ 시간×회의실 매트릭스
├─ 회의실 상세 (가용성 타임라인)
│  └─ 30분 슬롯 선택
├─ 예약 확인 모달
│  └─ 예약 완료
└─ 예약 관리 (마이 예약)
   └─ 취소 기능
```

## 디자인 — 그리드 시각 비교 (선택안)

철학: **"한눈에 비교하기"** — 모든 회의실을 동시에 보고 비교

컬러: 카드 스타일 / 시간대별 색상 (초록=가능, 주황=일부, 빨강=불가)

## 강점 & 고려사항
- **강점**: 모든 회의실 동시 비교, 시간대별 가용성 한눈에 파악
- **고려사항**: 모바일에선 카드 스택(스크롤) 필요, 반응형 그리드로 대응
