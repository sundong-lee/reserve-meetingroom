# 요구사항

## 앱 컨셉
직원들이 회의실을 조회하고 30분 단위로 예약할 수 있는 팀 내부 도구. 더블부킹을 자동으로 감지해서 예약 충돌을 방지합니다.

## 목적
- 팀 내부 도구
- 회의실 가용성 투명화
- 예약 충돌 제거

## 주 사용자와 사용 상황
직원들이 회의나 1on1을 잡을 때 "어느 회의실이 언제 비어있는가"를 빠르게 확인하고 예약하는 상황. 주로 업무 시간 중에 사용 (5분 내에 결정 완료).

## 핵심 기능
- **조회**: 회의실 목록 및 시간대별 가용성 확인
- **예약**: 30분 단위 예약 (더블부킹 감지)
- **취소**: 자신의 예약 취소

## 핵심 문제
"어느 회의실이 지금 / 오후 3시에 비어있는가?"를 빠르게 알아야 함.

## 데이터 구조
- **회의실**: id, 이름, 수용 인원, 위치
- **예약**: id, 회의실_id, 사용자, 예약_시작(30분 단위), 예약_종료(30분 단위), 생성_시간, 생성자

## 차별점
더블부킹을 자동으로 감지해서 "이 시간에는 예약할 수 없습니다" 안내.

## 범위 제외 (v2로 미루기)
- 캘린더 내보내기 (ics 등)
- 메일 알림
- 반복 예약
- 회의실 이미지/상세 설명
- 관리자 승인 워크플로우
